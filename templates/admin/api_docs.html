1. Authentifizierung

Alle API-Anfragen müssen einen gültigen API-Schlüssel im Header enthalten. 

# Header
X-API-Key: btf_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# Alternativ als Query-Parameter
curl "https://domain/api/v1/slots?api_key=btf_xxx"

API-Schlüssel erhalten Sie im Admin-Bereich unter "API-Schlüssel".

2. Zeit-Slots

Abruf von Zeit-Slots.

Endpunkt

GET /api/v1/slots

Query-Parameter

Parameter Typ Beschreibung
date string YYYY-MM-DD (optional)
upcoming boolean Nur zukünftige Slots (default: true)
limit integer Max. Anzahl (default: 10, max: 100)

Beispiel

curl -H "X-API-Key: btf_xxx" \
  "https://domain/api/v1/slots?upcoming=true&limit=20"

Antwort

{
  "success": true,
  "data": [
    {
      "id": 1,
      "date": "2024-01-15",
      "start_time": "10:00",
      "end_time": "10:30",
      "capacity": 5,
      "used_capacity": 2,
      "available": 3
    }
  ],
  "meta": {
    "total": 1,
    "date": "all",
    "upcoming": true
  }
}

3. Bestellungen

Abruf und Filterung von Bestellungen.

Endpunkte

GET /api/v1/orders
GET /api/v1/orders/:id

Query-Parameter

Parameter Typ Beschreibung
status string new, in_progress, ready, completed, cancelled
date string YYYY-MM-DD
slot_id integer Nach Slot filtern
from_date string Datum ab (YYYY-MM-DD)
to_date string Datum bis (YYYY-MM-DD)
limit integer max: 100

Beispiel

# Alle aktuellen Bestellungen
curl -H "X-API-Key: btf_xxx" \
  "https://domain/api/v1/orders?status=new"

# Bestellung nach ID
curl -H "X-API-Key: btf_xxx" \
  "https://domain/api/v1/orders/123"

# Bestellungen nach Datum
curl -H "X-API-Key: btf_xxx" \
  "https://domain/api/v1/orders?from_date=2024-01-01&to_date=2024-01-31"

4. Produkte

Abruf von Produktinformationen.

Endpunkt

GET /api/v1/products

Query-Parameter

Parameter Typ Beschreibung
active boolean Nur aktive (default: true)
product_type string Nach Typ filtern

Beispiel

curl -H "X-API-Key: btf_xxx" \
  "https://domain/api/v1/products"

5. Verfügbarkeit

Abruf der Produktverfügbarkeit.

Endpunkt

GET /api/v1/availability

Query-Parameter

Parameter Typ Beschreibung
product_id integer Erforderlich!
date string YYYY-MM-DD (optional)

Beispiel

curl -H "X-API-Key: btf_xxx" \
  "https://domain/api/v1/availability?product_id=1&date=2024-01-15"

Antwort

{
  "success": true,
  "data": {
    "product_id": 1,
    "date": "2024-01-15",
    "available_quantity": 10
  }
}

6. Health-Check

Prüfung der API-Verfügbarkeit (ohne API-Schlüssel).

Endpunkt

GET /api/v1/health

Beispiel

curl "https://domain/api/v1/health"

Antwort

{
  "success": true,
  "status": "healthy",
  "timestamp": "2024-01-15T10:30:00"
}
